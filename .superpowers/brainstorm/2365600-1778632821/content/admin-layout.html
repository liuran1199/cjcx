内容区域 — 随左侧导航切换

各功能页面关键元素

1. 考试管理

考试列表（表格）→ 新建考试（弹窗：考试名称、是否启用身份证验证）→ 每个考试有"导入成绩"按钮

2. Excel 导入

选择考试 → 上传 Excel → 预览前5行 → 确认列映射（系统自动识别，人工确认）→ 导入

3. 成绩数据

选择考试 → 搜索（姓名/学号）→ 表格展示 → 点击编辑 → 支持删除

4. CAS 配置

CAS 服务地址、启用开关、回调地址 — 简单表单

5. 管理员账号

账号列表 → 新增/删除管理员

6. 查询日志

时间、学生、考试、IP、结果 — 只读表格，支持按考试筛选
