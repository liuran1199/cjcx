核心组件

前端 SPA Vue 3 + Element Plus + Vite
学生查询页 + 管理员后台（同一应用，路由区分）
后端 API Node.js + Express
CAS 认证、成绩查询、Excel 导入、管理接口
数据库 SQLite
exams、scores、admins、logs 四张核心表
外部对接 学校 CAS 统一认证
ticket 验证 + JWT 签发

数据库核心表

表名 用途
exams 考试名称、身份证验证开关、成绩列定义（JSON）、创建时间
scores exam_id、学号、姓名、身份证号、成绩数据（JSON，动态列）
admins 管理员账号、密码哈希、CAS用户标识
query_logs 查询时间、学生学号、考试ID、IP、查询结果
