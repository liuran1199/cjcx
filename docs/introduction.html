1. 项目概述

学生成绩自助查询系统是一个为高校/中小学设计的轻量级成绩发布平台。学生通过企业微信或 PC 浏览器打开页面，自动完成 CAS 统一身份认证，立即查看考试成绩。管理员通过后台管理多场考试、上传 Excel 批量导入成绩、查看查询日志。

系统设计遵循零运维、易部署原则：SQLite 单文件数据库无需额外安装，Nginx + systemd 一行命令即可上线。身份证号采用 AES-256-GCM 加密存储，前端脱敏展示，满足个人信息保护要求。

2. 应用场景

期末/期中成绩发布

教师整理 Excel 上传，学生登录即查，无需逐个通知。支持自定义成绩列（总分、排名、各科分数等）。

招录选拔考试

如公务员招录、事业单位选拔等考试，支持开启身份证号二次验证，确保成绩仅本人可查。

模拟考试成绩反馈

一年多次模拟考，系统支持多考试独立管理，管理员可按需上架/下架，学生端仅显示当前开放的考试。

企业微信集成

企业微信已对接 CAS 统一认证，学生点开链接自动完成认证，无需输入账号密码，体验无缝。

3. 主要功能

3.1 学生端

功能说明
CAS 自动登录打开页面自动跳转统一认证，完成认证后回调并自动登录
考试列表展示所有管理员已上架的考试，含考试名称和时间
成绩查询选择考试后展示完整成绩单：姓名、学号、身份证号（脱敏）、各科分数
身份证验证考试开启身份验证时，需输入身份证号确认身份后方可查看成绩

3.2 管理后台

功能说明
考试管理新建/编辑/删除考试；自定义成绩列；一键开启/关闭考试上下架
Excel 导入上传 Excel 自动识别列名 → 列映射确认 → 数据预览 → 一键导入；支持下载导入模版
成绩管理按考试搜索、查看、编辑、删除单条成绩记录
CAS 配置配置统一认证服务器地址、回调地址、启用/禁用开关
账号管理创建/删除本地管理员账号（超级管理员可管理普通管理员）
查询日志记录每次查询的考试、学号、IP、结果（成功/失败/身份证不匹配），可追溯审计

4. 技术框架

层级技术说明
前端框架Vue 3 + Element Plus响应式 SPA，PC/移动端自适应
构建工具Vite极速开发服务器 + 生产构建
后端框架Node.js + ExpressRESTful API，中间件架构
数据库SQLite (better-sqlite3)零配置、单文件、WAL 模式，适合中小规模
认证JWT + CAS 协议HttpOnly Cookie 存储 JWT，CAS ticket 服务端校验
加密AES-256-GCM身份证号加密存储，scrypt 密钥派生，认证标签防篡改
Web 服务器Nginx静态资源 + API 反向代理
进程管理systemd开机自启，异常自动重启

6. 安全特性

措施说明
AES-256-GCM 加密身份证号使用 AES-256-GCM 认证加密，附带认证标签防篡改
前端脱敏展示身份证号仅显示前 4 位 + **** + 后 4 位（如 3401****1234）
HttpOnly CookieJWT 存储在 HttpOnly Cookie 中，JavaScript 无法读取，防止 XSS 窃取
CSP 内容安全策略限制脚本/样式/图片/字体加载来源，防止跨站脚本攻击
登录限流登录接口独立限流（5 次/分钟/IP），防止暴力破解
CORS 白名单仅允许配置的域名跨域访问，拒绝未知来源的请求
参数化查询所有数据库操作使用 ? 占位符参数化，杜绝 SQL 注入
环境变量密钥JWT_SECRET 和 ENCRYPTION_KEY 由环境变量注入，代码中无硬编码
上传大小限制Excel 文件上传限制 10MB，防止内存耗尽攻击

7. 部署说明

环境要求

  • Node.js 18+
  • Nginx（可选，生产环境推荐）
  • 操作系统：Linux（Ubuntu 20.04+/Debian/CentOS）

快速部署（5 分钟）

  1. 克隆仓库：git clone https://github.com/liuran1199/cjcx.git
  2. 配置环境变量：cp .env.example .env，填入随机生成的 JWT_SECRET 和 ENCRYPTION_KEY
  3. 安装依赖：cd server && npm install
  4. 构建前端：cd ../client && npm install && npm run build
  5. 启动服务：cd ../server && node index.js

首次启动自动创建 SQLite 数据库，并生成管理员随机密码打印到控制台。

生产环境部署

推荐 Nginx + systemd，详见项目 README.md 中的完整配置模板。
